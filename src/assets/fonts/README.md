Source Serif 4, version 4.004, self-hosted WOFF2 files from the [Google Fonts distribution](https://fonts.google.com/specimen/Source+Serif+4). Files are unmodified; exact upstream URLs and sizes are recorded in sources.json. SIL Open Font License 1.1 is included in LICENSE.md.

CSS uses the distribution's Unicode ranges, with weight 200–900 and optical size 8–60. The Latin normal font is 122,360 bytes and is preloaded only when Source Serif 4 is selected or is the default. Other character sets and italics load only when used. Vite emits hashed URLs. No visitor requests go to Google.

Source Serif 4 and Times New Roman share self-hosted Noto Serif SC 2.003 for Chinese, so glyphs and weights do not depend on installed system fonts. The WOFF2 files retain variable weights 200–900. CJK-only Unicode ranges keep Latin text in the selected typeface.

The Chinese homepage subset is 41,368 bytes; the remaining Chinese text in existing articles uses a 269,172-byte subset. Other covered characters load from locally stored Google Fonts shards as needed. Their ranges exclude the two common subsets to avoid redundant downloads. Provenance, subset characters and the SIL OFL license are in noto-serif-sc/.

Sans remains a system font. Times New Roman uses the installed font for Latin text. All webfonts are served locally with hashed URLs.
