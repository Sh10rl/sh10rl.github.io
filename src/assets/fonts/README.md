Source Serif 4, version 4.004, self-hosted WOFF2 files from the [Google Fonts distribution](https://fonts.google.com/specimen/Source+Serif+4). The files from Google are unmodified; exact upstream URLs and sizes are recorded in sources.json, with the one subset made from them. SIL Open Font License 1.1 is included in LICENSE.md.

CSS uses the distribution's Unicode ranges, with weight 200–900 and optical size 8–60. Normal Latin text is set from a subset, `site` (52,812 bytes against the Latin file's 122,360): ASCII and the 16 other characters the pages show or the browser draws (the hyphen of `hyphens: auto`, the ellipsis of `text-overflow`, the quotation marks of `<q>`), with the layout features the CSS uses and weights 400–900 (the CSS sets 400 to 750). `uv run scripts/generate-fonts.py` makes it from the Latin file with the Chinese subsets below, and writes its face to src/styles/fonts-latin.css. That face comes after fonts.css, so browsers take it first for its characters and load Google's Latin file only for another, which the build reports. The subset is preloaded only when Source Serif 4 is selected or is the default. Other character sets and italics load only when used. Vite emits hashed URLs. No visitor requests go to Google.

Source Serif 4 and Times New Roman share self-hosted Noto Serif SC 2.003 for Chinese, so glyphs and weights do not depend on installed system fonts. The WOFF2 files retain variable weights 200–900. CJK-only Unicode ranges keep Latin text in the selected typeface.

The Chinese subsets come from the built pages: `home` holds the 129 characters of the index pages (46,324 bytes) and `articles` the 752 others that any page shows (266,216 bytes). After `pnpm build`, `uv run scripts/generate-fonts.py` remakes both from the pinned source in noto-serif-sc/sources.json and rewrites src/styles/fonts-cjk.css; build again afterwards. The build reports when a page shows characters the subsets lack (scripts/font-coverage.ts). Such characters load a shard each, or on an index page the whole `articles` subset: the newest post's title once made the home page load 592 KB of Chinese fonts instead of 41 KB. Other covered characters load from locally stored Google Fonts shards as needed. Their faces are in src/styles/fonts-cjk-shards.css, which src/scripts/main.ts links at low priority after the page has loaded, and their ranges exclude the two subsets. Provenance, subset characters and the SIL OFL license are in noto-serif-sc/.

Sans remains a system font. Times New Roman uses the installed font for Latin text. All webfonts are served locally with hashed URLs.
