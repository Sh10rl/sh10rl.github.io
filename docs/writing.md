开发模式提供网页和 Markdown 两种写作方式。

运行 `pnpm dev`，打开终端显示的地址，点击首页的 `New article`，或访问 `/write/`。

网页编辑器支持 Markdown、公式和本地图片预览。点击 `Save` 或按 `⌘S` / `Ctrl+S` 保存到 `posts/`；`Open article` 打开实际文章。标题来自首个 `# 标题`，日期和文件名自动生成，分类可选。再次编辑会更新同一文件。若文件已被本地编辑器修改，网页会保留当前文字并提示重新载入。

也可以直接创建 `posts/2026-09-28-my-article.md`：

```md
# 文章标题

正文从这里开始。
```

无需 YAML。标题取首个一级标题或文件名；日期依次取可选的 `date`、文件名前缀、Git 首次提交日期、文件创建时间；摘要、阅读时长和语言自动计算。放在 `posts/learn/` 这样的分类目录中即可归类。文件或目录以 `_` 开头时作为草稿，仅开发模式显示。

需要覆盖默认值时，可以只写必要字段：

```md
---
tags: [Linux]
---
# 文章标题

正文。
```

编辑器及文件写入接口只存在于开发服务器，不会进入静态构建。保存不会提交或推送 Git。
