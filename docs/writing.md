运行 `pnpm dev`，打开终端显示的地址。直接编辑 `posts/` 下的 Markdown，保存后页面自动刷新。

新建文章，例如 `posts/2026-09-28-my-article.md`：

```md
# 文章标题

正文从这里开始。
```

无需 YAML。标题取首个一级标题或文件名；日期依次取可选的 `date`、文件名前缀、Git 首次提交日期、文件创建时间；摘要、阅读时长和语言自动计算。放在 `posts/learn/` 这样的分类目录中即可归类。文件或目录以 `_` 开头时作为草稿，仅开发模式显示。

需要覆盖默认值时，可以只写必要字段：

```md
---
tags: [Linux]
---
# 文章标题

正文。
```

发布时提交修改并推送到 `main`。
